Barnen i flexboxen

Behållaren bestämmer riktning och justering. Barnet bestämmer om det får växa, krympa och hur brett det vill börja.

Mål: kunna göra kort lika breda, låta ett fält ta resten av raden och hålla en sidospalt på en fast bredd.

Repetition

Behållaren från förra lektionen

flex-directionrad eller kolumn – det är huvudaxeln
justify-contentfördelar barnen längs huvudaxeln
align-itemsjusterar barnen på tväraxeln
gap / flex-wrapluckor mellan barnen, och ny rad när det tar slut

Inget av det säger hur brett ett enskilt kort ska vara. Det gör barnen.

Tre reglage

basis, grow och shrink

flex-basis

Hur brett barnet vill börja, innan det blir yta över eller ont om plats.

flex-grow

Hur stor del av ytan som blir över barnet tar. 0 betyder: väx inte.

flex-shrink

Om barnet får krympa när raden är för smal. Standard är 1: ja.

Standard

Om du inte skriver något är det flex: 0 1 auto. Barnet växer inte, det får krympa, och startbredden är innehållets bredd.

flex-basis

Startbredden

.första { flex-basis: 40%; }   /* de andra: auto */
40 %autoauto

auto betyder ungefär: så brett som innehållet, eller som width om du satt en. flex-basis vinner över width när båda finns.

flex-grow

Dela på ytan som blir över

.kort { flex-grow: 1; flex-basis: 0; }
.mitt { flex-grow: 2; }
121
basis 0

Med flex-basis: 0 räknas inte textens bredd in först. Då blir bredden verkligen 1 mot 2 mot 1. Sätter du bara flex-grow: 1 är basis fortfarande auto, och innehållet påverkar.

flex-shrink

När raden är för smal

.kort { flex: 1 1 8rem; }
.fast { flex-shrink: 0; }   /* den här vägrar krympa */
krymperfast 8remkrymper

Rutan är 18rem och varje barn vill ha 8rem. De som får krympa ger sig. Den röda behåller sin bredd – då får de andra ta smällen.

Kortformen

flex är tre värden

flex: 1;          /* grow 1, shrink 1, basis 0 */
flex: 2;          /* dubbelt så stor del */
flex: 0 0 12rem;  /* väx inte, krymp inte, 12rem */
flex: 0 0 auto;   /* så bred som innehållet */
Sökfält · flex: 1Sök
Lika kort

Skriv flex: 1, inte bara flex-grow: 1, när korten ska dela raden lika. Basis 0 gör att textlängden inte snedvrider dem.

Förutsäg · flex

Fältet tar resten, knappen inte

Ett sökfält ska fylla det som blir över på raden. Knappen ska vara så bred som ordet ”Sök” och inte krympa. Vilka två flex-värden?

.sok   { flex: 1; }
.knapp { flex: 0 0 auto; }

flex: 1 delar på ledig yta. 0 0 auto låser knappen vid innehållets bredd.

align-self

Ett barn som bryter mönstret

.rad  { align-items: center; }
.sista { align-self: flex-end; }
centercenterflex-end

align-items gäller alla barn. align-self skriver över det för ett enda. Samma värden: flex-start, center, flex-end, stretch.

Övning · navbar

Sökfältet tar resten

Behåll CSS:en från lektion 8. Byt innehållet i .navbar mot det här.

<header class="navbar">
  <a class="logo" href="#">Studio</a>
  <input class="sok" type="search" placeholder="Sök">
  <button>Sök</button>
</header>
1

.sok { flex: 1; }. Fältet tar ledig yta mellan logotyp och knapp.

2

.logo, button { flex: 0 0 auto; }. De blir så breda som innehållet och vägrar krympa.

3

Gör fönstret smalt. Fältet ger sig. Logotyp och knapp behåller sin bredd.

Kontroll

En rad: Studio, ett fält som fyller mitten, och en knapp så bred som ordet Sök.

Övning · kort

Bild, text och pris på en rad

<article class="kort">
  <div class="bild">Bild</div>
  <div class="text"><h2>Stol</h2><p>Ek, 120 cm.</p></div>
  <span class="pris">1 200 kr</span>
</article>
1

.kort { display: flex; gap: 1rem; align-items: center; }. Ge .bild en bakgrund så rutan syns.

2

.bild { flex: 0 0 6rem; } och .text { flex: 1; }. Bilden är låst. Texten tar resten.

3

.pris { align-self: flex-start; }. Priset sitter uppe i hörnet. Texten är kvar i mitten.

Kontroll

Bilden ändrar inte bredd när du drar i fönstret. Texten gör det. Priset ligger högre än texten.

Lektion 9 · Avslut

Klar när…

  • ✓Du kan förklara flex-basis, flex-grow och flex-shrink med vardagsord.
  • ✓Du kan skriva flex: 1 för att dela lika, och flex: 0 0 12rem för en fast bredd.
  • ✓Du vet att bara flex-grow: 1 inte är samma sak som flex: 1.
  • ✓Du kan lyfta ut ett barn med align-self.
