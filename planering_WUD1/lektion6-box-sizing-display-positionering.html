Från låda till layout

Vi gör storleksräkningen enklare med box-sizing, lär oss hur block och inline beter sig – och hur position kan flytta ett element.

Mål: kunna räkna rätt med border-box, skilja på block och inline samt välja rätt position i enkla situationer.

total: 248px

Båda lådorna har width: 200px;, padding: 20px; och border: 4px solid;. Ändå blir de olika breda.

Förutsäg · box-sizing

Hur stort blir innehållet?

.box {
  box-sizing: border-box;
  width: 200px;
  padding: 20px;
  border: 4px solid;
}

Hela lådan är 200px. Hur mycket plats får innehållet kvar?

200 − (2 × 20) − (2 × 4) = 152px

Med border-box räknas padding och border inifrån den angivna bredden. Innehållet får det som blir över.

Rekommendation

Använd border-box överallt

*, *::before, *::after {
  box-sizing: border-box;
}
  • 1width blir den totala bredden – lätt att räkna.
  • 2Padding och border spränger inte längre layouten.
  • 3Samma regel används i nästan alla moderna projekt.
Blockelement

Block tar hela raden

Block 1 – hela förälderns bredd
Block 2 – börjar på ny rad
  • ✓Börjar alltid på en ny rad.
  • ✓Tar upp hela tillgängliga bredden.
  • ✓width, height, margin och padding fungerar fullt ut.

Exempel: div, p, h1, ul, li – bygger sidans struktur.

Inline-element

Inline ligger kvar på raden

Här är ett inline-element mitt i texten och ett till på samma rad.

  • ✓Börjar inte på en ny rad.
  • ✓Tar bara upp så mycket plats som innehållet behöver.
  • ✗width och height har ingen effekt.
  • ✗Endast horisontell margin och padding fungerar som väntat.

Exempel: span, a, strong, em – används inuti text.

Positionering

Fem värden för position

static

Standard. Elementet följer sidans normala flöde.

relative

Flyttas från sin plats med top, right, bottom, left.

absolute

Positioneras mot närmaste förälder med position. Lämnar flödet.

fixed

Fäst mot webbläsarfönstret – stannar även när du scrollar.

sticky

Som static tills du scrollar till en gräns – då följer den med.

Viktigt

Börja med sidans vanliga flöde. position är främst för överlägg, popups och små justeringar – inte en generell layoutlösning.

Förutsäg · position

Vilket värde passar?

En meny ska ligga högst upp i fönstret och följa med när användaren scrollar – men bara så länge man är kvar i sidhuvudets område. Vilket position-värde passar?

position: sticky; top: 0; – elementet ligger i flödet tills scrollgränsen nås, då följer det med.

fixed skulle också stanna, men då lossnar elementet helt från flödet och ligger kvar även utanför sitt område.

Kombinera allt

Header med navigation

.header {
  position: sticky;
  top: 0;
  padding: 16px 24px;
  border-bottom: 3px solid #3498db;
  box-sizing: border-box;
}
.nav a {
  display: inline-block;
  padding: 12px 16px;
  margin: 0 4px;
}
  • 1sticky gör att headern följer med vid scroll.
  • 2border-box gör att padding inte spränger bredden.
  • 3inline-block ger länkar klickbar yta och avstånd.
